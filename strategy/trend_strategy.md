# 趋势交易（底部偏右进场）

## 市场环境过滤

> 趋势系统死于震荡市，环境过滤是第一道风控。
> 对应代码：`src/analysis/market_gate.py`（策略规划器诊断同源采集；其他策略复用门控时再抽离）。

### 硬拦截层（极端环境，触发任一即当日锁仓+清仓）

优先级最高，不看门控得分、不看评分系数，直接执行。

| **拦截项** | **条件**                  | **含义**     |
| ------- | ----------------------- | ---------- |
| 成交额冰点   | 两市成交额 \< 1.5万亿 且连续 ≥ 3天 | 流动性枯竭，市场休克 |
| 千股跌停    | 跌停 ≥ 50 且跌停 > 涨停 × 3     | 极端恐慌，系统性风险 |
| 指数暴跌    | 上证单日跌幅 > 3%             | 单日崩盘，不可逆   |
| 成交量骤降   | 当日成交量 \< 近20日均量 × 0.5   | 流动性休克，量能断崖 |

> **"千股跌停"修复**：增加绝对数量下限（跌停 ≥ 50），避免涨停很少时因乘法误触发。

**触发硬拦截的动作：** ❌ 禁止开新仓；🏃 持仓当天全部清仓（不等 MA10 破位，不等连续 2 天确认）。

### 门控检查（≥2项通过才开仓）

| **序号** | **检查项**             | **具体条件**               | **数据来源**      | **层级** |
| ------ | ------------------- | ---------------------- | ------------- | ------ |
| ①      | 上证收盘 > MA20         | 趋势底线                   | akshare 上证日线  | 宏观     |
| ②a     | 两市成交额 ≥ 1.5万亿        | 绝对流动性                  | akshare 全市场行情 | 宏观     |
| ②b     | 成交量 > 近20日均量        | 相对流动性（放量优于缩量，同比比较）    | akshare 上证日线  | 宏观     |
| ③      | 涨停 ≥ 30 且 涨停 > 跌停 × 1.5 | 情绪底线（数量+比值双重确认）        | akshare 涨跌停池  | 盘面     |

只有这 4 项是纯市场环境判断，不依赖个股/板块数据的任何维度。触发硬拦截时跳过门控直接锁仓。

**各阈值对应的流动性状态（参考，不纳入门控）：**

| **指标** | **冰点**  | **一般**    | **正常**   | **充裕**     | **极度宽松** |
| ------ | ------- | --------- | -------- | ---------- | -------- |
| 两市成交额  | \<1.5万亿 | 1.5\~2万亿  | 2\~2.5万亿  | 2.5\~3万亿   | ≥3万亿      |
| 涨停家数   | \<20    | 20\~50    | 50\~80   | 80\~100    | >100     |
| 跌停家数   | >30     | 15\~30    | 5\~15    | \<5        | \<3      |
| 涨停/跌停比 | \<1     | 1\~2      | >2       | >3         | >5       |
| 连板高度   | ≤2板     | 2\~3板     | 3\~5板    | 5\~7板      | ≥7板      |

### 市场状态分级与响应动作

门控通过（≥2项）后，按市场状态决定评分系数和持仓管理策略。判定优先级：trending_down > trending_up > sideways > weak_up > chaos。

| **状态**             | **判定条件**                         | **评分系数** | **开仓** | **持仓管理**    |
| ------------------ | -------------------------------- | -------- | ------ | ----------- |
| **trending\_down** | MA5\<MA10\<MA20 + 收盘\<MA10       | ×0.5     | ❌ 禁止开仓 | 收紧卖出（加速退出）  |
| **trending\_up**   | MA5>MA10>MA20 + 收盘>MA10 + 门控≥2   | ×1.0     | ✅ 正常买入 | 正常卖出规则      |
| **sideways**       | 收盘偏离MA20 \<1.5%                  | ×0.8     | ❌ 禁止开仓 | 自然退出（不主动砍仓） |
| **weak\_up**       | 收盘>MA20 + 门控≥2 + 非以上三种          | ×0.85    | ✅ 谨慎买入 | 正常卖出规则      |
| **chaos**          | 门控\<2（即0或1项通过）                 | 不开仓      | ❌ 禁止开仓 | 不开新仓        |

> **设计说明**：trending\_down 排在首位判定——均线空头时无论门控通过多少项都不开仓，均线结构本身已给出最强信号。

### trending_down 下的收紧卖出规则

进入 trending_down 状态后，持仓卖出规则从正常版收紧为加速版：

| **卖出规则** | **正常版**                 | **trending\_down版**       |
| -------- | ----------------------- | ------------------------- |
| 破MA10    | 连续**2天**收盘 \< MA10      | **1天**收盘 \< MA10就走        |
| 放量破位     | 量比≥2 + 收盘\<MA5减半 / \<MA10清仓 | 量比≥1.5 + 同上 |
| 阶段高点回撤   | 回撤≥5%减仓                | 回撤≥3%减仓                  |
| 板块走弱     | 板块明显走弱（≤-2%）减仓         | 板块走弱（≤-1%）立刻减仓            |

以下仅做辅助判断，不影响开仓/锁仓判定：

| **指标** | **参考逻辑**                    | **含义**   | **数据来源**    | **实现状态** |

### 执行流程图

```
每日收盘 →
  ├─ 硬拦截检查
  │    ├─ 触发任一 → 锁仓+全清，结束
  │    └─ 未触发 → 继续
  ├─ 门控检查（4项）
  │    ├─ 通过≥2项 → 继续判定状态
  │    ├─ 通过<2项 → chaos状态，不开仓
  ├─ 市场状态判定（按优先级）
  │    ├─ trending_down → ×0.5，不开仓+收紧卖出【最先判定】
  │    ├─ trending_up → ×1.0，正常买入+正常持仓
  │    ├─ sideways → ×0.8，不开仓+自然退出
  │    ├─ weak_up → ×0.85，谨慎买入+正常持仓
  │    └─ chaos → 不开仓+不开新仓
```

### 关于主线

门控中**不含板块/主线检查**。主线相关逻辑应放在**选股环节**而非市场门控，原因：

1. **门控回答"能不能交易"**，只需宏观+流动性+情绪数据，不依赖个股/板块维度。
2. **主线回答"能不能找到猎物"**，属于选股层面的过滤条件——个股是否属于今日活跃板块，应与股票池绑定。
3. 如果把主线放在门控，"今天有主线但你的自选股全都不在主线里"和"今天没主线但你的某只股独立逻辑走强"都会产生错误判断。

## 选股 stock_selector

**两层结构（与代码一致）：**

**① 松筛（观察池发现，`DEFAULT_SCREEN_KEYWORD`）：**

- 市值 30 亿 ~ 500 亿
- 均线多头排列
- 换手率 > 3%（宽松口径，保证池子不会饿死）
- 排除科创板/创业板/北交所/ST

**② 精筛（signal_detector 信号触发条件）：**

- 5日线 > 10日线 > 20日线（均线多头排列）
- 收盘涨幅 2%-7%（信号 1 当日涨跌幅温和：−5% < 涨跌幅 < 7%）
- 换手率 > 3%
- 成交额充足，流动性达标
- 非连续加速状态（近3日<18%、近5日<30%）

**板块条件：** 属于当前主线板块，或板块强度前列。

## 观察池

### 加入

通过筛选的个股进入观察池，**趋势不走坏即保留**：

- 未有效跌破10日线
- 板块未明显退潮

**删除条件（满足其一）：**

- 连续2天收盘跌破10日线
- 放量长阴破趋势
- 板块明显退潮

### 剔除

| **规则**        | **触发条件**                        |
| ------------- | ------------------------------- |
| **连续破 10 日线** | 连续 2 天收盘价 \< MA10               |
| **放量长阴**      | 单日跌幅 ≥ 5% + 量比 ≥ 2 + 收盘 \< MA10 |
| **情绪过热**      | 近 5 日换手均值 > 5% **且** > 近 20 日换手均值的 2 倍（双条件 AND，防低基数比值虚高误杀） |
| **流动性枯竭**     | 近 5 日平均换手 \< 1% 且没有任何一天 ≥ 3%    |

## 买点

### 信号 1：缩量回踩 MA5（最优买点）

必须**全部满足**以下 8 项：

| **条件**         | **具体标准**                                                                   |
| -------------- | -------------------------------------------------------------------------- |
| ① 守住 MA5       | 收盘价 ≥ MA5 × 0.995（允许微破 0.5%）                                               |
| ② 不放量          | 当日成交量 \< 5 日均量 × 1.1                                                       |
| ③ 乖离率合理        | −1.5% \< bias\_ma5 \< 3.5%                                                 |
| ④ 日内有承接        | 收盘位置在日内区间上半部（close\_position > 0.4）且下影线占比 > 10%                            |
| ⑤ 换手率达标        | > 3%                                                                       |
| ⑥ 非情绪过热        | 近 3 日涨幅 \< 18%、近 5 日涨幅 \< 30%、近 5 日最大乖离 \< 12%、近 3 日最大振幅 \< 15%、当日涨幅 \< 7% |
| ⑦ 前期在 MA5 上方运行 | 过去 5 天至少 3 天收盘 > MA5（确认为"第一次"回踩而非持续破位）                                     |
| ⑧ 当日涨跌幅温和      | −5% \< 涨跌幅 \< 7%                                                           |

**额外形态标注（加分但不影响触发）：**

- 换手 > 8% 且涨幅 2%–5% → 标注 ⭐龙头特征
- 前一日大阳线（涨幅 > 3%）+ 后三日连续缩量阴线 → 标注 📐一阳三阴形态

| **维度**             | **满分** | **最佳区间**                          |
| ------------------ | ------ | --------------------------------- |
| 乖离率 bias\_ma5      | 25     | 贴近 +0.5%                          |
| 量比 volume\_ratio   | 20     | 0.7 附近（适度缩量）                      |
| 涨跌幅 pct\_change    | 15     | 接近 0                              |
| 换手率 turnover\_rate | 15     | 4%–7%                             |
| 日内承接               | 15     | close\_position > 0.6 + 下影线 > 20% |
| 前期站上 MA5 天数        | 10     | 越多越好                              |

最终评分范围：**50–95**

### 信号 2：回踩 MA10（次优买点）

当信号 1 不满足（跌破了 MA5）时才检查，需满足：

| **条件**        | **具体标准**                        |
| ------------- | ------------------------------- |
| 不放量           | 同上，当日成交量 \< 5 日均量 × 1.1         |
| 触及 MA10 且收盘守住 | 最低价 ≤ MA10 × 1.01 且收盘价 ≥ MA10   |
| 日内有承接         | close\_position > 0.4，下影线 > 10% |
| 换手率达标         | > 3%                            |
| 非情绪过热         | 同信号 1                           |
| 确实跌破了 MA5     | holds\_ma5 = False              |

信号 2 评分上限 85（对比信号 1 上限 95），标注"需次日弱转强确认"。

| **维度**             | **满分** | **最佳区间**                          |
| ------------------ | ------ | --------------------------------- |
| 乖离率 bias\_ma5      | 15     | −1% 附近                            |
| 量比 volume\_ratio   | 20     | 0.6 附近                            |
| 涨跌幅 pct\_change    | 15     | −1% 附近                            |
| 换手率 turnover\_rate | 20     | 5% 附近                             |
| 日内承接               | 15     | close\_position > 0.4 + 下影线 > 10% |
| 触及 MA10            | 15     | 有触及 = 15，无 = 0                    |

最终评分范围：**30–85**

## 卖出 信号已实现，执行用户主动

> ✅ **对应代码：`src/analysis/strategy/sell_rules.py`**。每日盘后读取妙想模拟仓持仓（用户手动同步真实持仓），
> 检测卖出信号并写入日报；**下单仍由用户主动执行**，系统不自动交易。
> 仅对股票持仓（A 股代码前缀白名单）检测卖出信号；ETF/基金/债券等非股票持仓由 ETF 系统管理，不参与。
> 板块行情多源回退（akshare 新浪 → 东财 → efinance），数据缺失时板块类规则跳过。

**量比口径：** 当日成交量 ÷ 前 5 日均量（不含当日）。**阶段高点/关键平台：** 近 20 个交易日（不含当日）的最高/最低收盘价。

**第一卖点（减仓50%），满足其一：**

| 规则            | 量化条件（正常版）                              |
| ------------- | -------------------------------------- |
| 放量跌破5日线       | 量比≥2 且 收盘<MA5                           |
| 高位长阴吞没        | 前日阳线被当日阴线吞没 + 当日跌幅≤-3% + 高位（近5日涨幅≥10% 或 收盘≥20日高点×0.97） |
| 从阶段高点回撤≥5%    | 收盘 < 近20日最高收盘 × 0.95                   |
| 板块明显走弱        | 所属行业板块当日跌幅≤-2%（数据缺失时该条跳过）               |

**减仓后剩余仓位：** 止损线上移至10日线，收盘跌破则清仓。
> ⚠️ 实现说明：系统不做减仓阶段跟踪（无法确认用户是否已执行减半），此条以信号文案提醒形式输出，由用户自行执行。

**第二卖点（全仓清仓），满足其一：**

| 规则        | 量化条件（正常版）                      |
| --------- | ------------------------------ |
| 连续跌破10日线  | 连续 2 日收盘 < MA10                |
| 放量跌破10日线  | 量比≥2 且 收盘<MA10                  |
| 主线明显退潮    | 近似：所属板块当日跌幅≤-3%（数据缺失时该条跳过）     |
| 个股跌破关键平台  | 收盘 < 近20日最低收盘                  |

**止盈保护（建议减半）：** 盈利≥15% 且 放量滞涨（量比≥2 且 当日涨幅<2%，或收盘位于日内区间下半部），余仓继续按趋势持有。

> ⚠️ **trending_down 收紧版**（按上文"trending_down 下的收紧卖出规则"执行）：MA10 破位缩为 **1 天**、
> 阶段高点回撤阈值缩为 **3%**、量比阈值降为 **1.5**、板块走弱阈值放宽为 **-1%**。

**市场状态分支：** trending_up/weak_up 用正常版；trending_down 用收紧版；sideways/chaos **自然退出，不输出主动卖出信号**；市场门控硬拦截触发时所有持仓直接清仓信号。

> 核心逻辑：趋势破坏才卖。大利润来自少数超预期趋势，小亏多次靠大赚覆盖。

## 配置与铁律规则

> ⚠️ **以下为个人交易纪律（无代码实现，由用户自行遵守）。**

- 100%现金，仅做高流动性标的的趋势短线交易，不碰ST、低流动性小盘股
- 绝对不追加本金，固定1万元额度，亏完即停止短线交易
- 单笔交易亏损不超过本金的2%（200元），严格止损
- 总账户回撤超20%（剩余8000元），立即暂停交易1个月，复盘后再重启
- 盈利超50%，将超出部分的50%转出至主账户落袋为安，不把盈利再投入博弈
