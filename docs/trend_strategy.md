# 趋势交易（底部偏右进场）

## 市场环境过滤

见 [market.md](./market.md)

- **硬拦截**：4 项极端条件，触发任一即锁仓+全清
- **门控检查**：4 项（趋势① / 量能②a+②b / 情绪③），≥2 项通过才开仓
- **市场状态**：5 级分级（trending_up / weak_up / sideways / trending_down / chaos），不同状态对应不同评分系数和持仓管理策略

> 趋势系统死于震荡市，环境过滤是第一道风控。

---

## 选股 stock_selector

**个股条件（每日筛选）：**

- 5日线 > 10日线 > 20日线（均线多头排列）
- 收盘涨幅 2%-7%
- 换手率 > 5%
- 成交额充足，流动性达标
- 非连续加速状态

**板块条件：** 属于当前主线板块，或板块强度前列。

> ⚠️ **TODO**：主线板块的量化定义与筛选逻辑待补充。当前门控已移除主线检查（见 market.md 附录），主线过滤应在选股环节实现：个股所属板块需为当日强势板块（如涨幅前 5 行业），非主线个股降优先级或跳过。需明确板块数据来源（akshare 行业板块涨跌幅）和定义标准（如"今日涨幅前3板块"或"连续N日涨幅排名前5"）。

## 观察池

### 加入

通过筛选的个股进入观察池，**趋势不走坏即保留**：

- 未有效跌破10日线
- 板块未明显退潮

**删除条件（满足其一）：**

- 连续2天收盘跌破10日线
- 放量长阴破趋势
- 板块明显退潮

### 剔除

| **规则**        | **触发条件**                        |
| ------------- | ------------------------------- |
| **连续破 10 日线** | 连续 2 天收盘价 \< MA10               |
| **放量长阴**      | 单日跌幅 ≥ 5% + 量比 ≥ 2 + 收盘 \< MA10 |
| **情绪过热**      | 近 5 日换手均值 > 近 20 日换手均值的 2 倍     |
| **流动性枯竭**     | 近 5 日平均换手 \< 1% 且没有任何一天 ≥ 3%    |

## 买点

### 信号 1：缩量回踩 MA5（最优买点）

必须**全部满足**以下 8 项：

| **条件**         | **具体标准**                                                                   |
| -------------- | -------------------------------------------------------------------------- |
| ① 守住 MA5       | 收盘价 ≥ MA5 × 0.995（允许微破 0.5%）                                               |
| ② 不放量          | 当日成交量 \< 5 日均量 × 1.1                                                       |
| ③ 乖离率合理        | −1.5% \< bias\_ma5 \< 3.5%                                                 |
| ④ 日内有承接        | 收盘位置在日内区间上半部（close\_position > 0.4）且下影线占比 > 10%                            |
| ⑤ 换手率达标        | > 3%                                                                       |
| ⑥ 非情绪过热        | 近 3 日涨幅 \< 18%、近 5 日涨幅 \< 30%、近 5 日最大乖离 \< 12%、近 3 日最大振幅 \< 15%、当日涨幅 \< 7% |
| ⑦ 前期在 MA5 上方运行 | 过去 5 天至少 3 天收盘 > MA5（确认为"第一次"回踩而非持续破位）                                     |
| ⑧ 当日涨跌幅温和      | −5% \< 涨跌幅 \< 7%                                                           |

**额外形态标注（加分但不影响触发）：**

- 换手 > 8% 且涨幅 2%–5% → 标注 ⭐龙头特征
- 前一日大阳线（涨幅 > 3%）+ 后三日连续缩量阴线 → 标注 📐一阳三阴形态

| **维度**             | **满分** | **最佳区间**                          |
| ------------------ | ------ | --------------------------------- |
| 乖离率 bias\_ma5      | 25     | 贴近 +0.5%                          |
| 量比 volume\_ratio   | 20     | 0.7 附近（适度缩量）                      |
| 涨跌幅 pct\_change    | 15     | 接近 0                              |
| 换手率 turnover\_rate | 15     | 4%–7%                             |
| 日内承接               | 15     | close\_position > 0.6 + 下影线 > 20% |
| 前期站上 MA5 天数        | 10     | 越多越好                              |

最终评分范围：**50–95**

### 信号 2：回踩 MA10（次优买点）

当信号 1 不满足（跌破了 MA5）时才检查，需满足：

| **条件**        | **具体标准**                        |
| ------------- | ------------------------------- |
| 不放量           | 同上，当日成交量 \< 5 日均量 × 1.1         |
| 触及 MA10 且收盘守住 | 最低价 ≤ MA10 × 1.01 且收盘价 ≥ MA10   |
| 日内有承接         | close\_position > 0.4，下影线 > 10% |
| 换手率达标         | > 3%                            |
| 非情绪过热         | 同信号 1                           |
| 确实跌破了 MA5     | holds\_ma5 = False              |

信号 2 评分上限 85（对比信号 1 上限 95），标注"需次日弱转强确认"。

| **维度**             | **满分** | **最佳区间**                          |
| ------------------ | ------ | --------------------------------- |
| 乖离率 bias\_ma5      | 15     | −1% 附近                            |
| 量比 volume\_ratio   | 20     | 0.6 附近                            |
| 涨跌幅 pct\_change    | 15     | −1% 附近                            |
| 换手率 turnover\_rate | 20     | 5% 附近                             |
| 日内承接               | 15     | close\_position > 0.4 + 下影线 > 10% |
| 触及 MA10            | 15     | 有触及 = 15，无 = 0                    |

最终评分范围：**30–85**

## 卖出 无 暂时用户主动

**第一卖点（减仓50%），满足其一：**

- 放量跌破5日线
- 高位长阴吞没
- 从阶段高点回撤≥5%
- 板块明显走弱

**减仓后剩余仓位：** 止损线上移至10日线，收盘跌破则清仓。

**第二卖点（全仓清仓），满足其一：**

- 连续2日收盘跌破10日线
- 放量跌破10日线
- 主线明显退潮
- 个股跌破关键平台

**止盈保护（补充）：** 当盈利≥15%且出现放量滞涨时，可主动止盈半仓，余仓继续按趋势持有。

> ⚠️ **注意**：以上卖出规则为正常版。当市场处于 trending\_down 状态时，应按 [market.md](./market.md#四trending_down-下的收紧卖出规则) 的收紧版执行（MA10 破位缩为 1 天、回撤阈值缩为 3%、放量长阴阈值降低等）。

> 核心逻辑：趋势破坏才卖。大利润来自少数超预期趋势，小亏多次靠大赚覆盖。

---

## 止损 无 暂时用户主动

**普通止损：** 买入逻辑被否定（回踩失败、跌破10日线、板块转弱），收盘执行。

**极端止损（盘中直接走）：** 突发闪崩、放量直线跳水、板块崩盘。

## 配置与铁律规则

- 100%现金，仅做高流动性标的的趋势短线交易，不碰ST、低流动性小盘股
- 绝对不追加本金，固定1万元额度，亏完即停止短线交易
- 单笔交易亏损不超过本金的2%（200元），严格止损
- 总账户回撤超20%（剩余8000元），立即暂停交易1个月，复盘后再重启
- 盈利超50%，将超出部分的50%转出至主账户落袋为安，不把盈利再投入博弈
