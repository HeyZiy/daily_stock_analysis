# 市场环境门控

> 主动账户系统的市场准入模块。独立笔记，主策略引用此处。

---

## 一、硬拦截层（极端环境，触发任一即当日锁仓+清仓）

优先级最高，不看门控得分、不看评分系数，直接执行。

| **拦截项** | **条件**                  | **含义**     |
| ------- | ----------------------- | ---------- |
| 成交额冰点   | 两市成交额 \< 1.5万亿 且连续 ≥ 3天 | 流动性枯竭，市场休克 |
| 千股跌停    | 跌停 ≥ 50 且跌停 > 涨停 × 3     | 极端恐慌，系统性风险 |
| 指数暴跌    | 上证单日跌幅 > 3%             | 单日崩盘，不可逆   |
| 成交量骤降   | 当日成交量 \< 近20日均量 × 0.5   | 流动性休克，量能断崖 |

> **"千股跌停"修复**：增加绝对数量下限（跌停 ≥ 50），避免涨停很少时因乘法误触发。

**触发硬拦截的动作：**

- ❌ 禁止开新仓
- 🏃 持仓当天全部清仓（不等MA10破位，不等连续2天确认）

---

## 二、门控检查（≥2项通过才开仓）

| **序号** | **检查项**             | **具体条件**               | **数据来源**      | **层级** |
| ------ | ------------------- | ---------------------- | ------------- | ------ |
| ①      | 上证收盘 > MA20         | 趋势底线                   | akshare 上证日线  | 宏观     |
| ②a     | 两市成交额 ≥ 1.5万亿        | 绝对流动性                  | akshare 全市场行情 | 宏观     |
| ②b     | 成交量 > 近20日均量        | 相对流动性（放量优于缩量，同比比较）    | akshare 上证日线  | 宏观     |
| ③      | 涨停 ≥ 30 且 涨停 > 跌停 × 1.5 | 情绪底线（数量+比值双重确认）        | akshare 涨跌停池  | 盘面     |

**开仓门槛：≥2项通过**

只有这4项是纯市场环境判断，不依赖个股/板块数据的任何维度。触发硬拦截时跳过门控直接锁仓。

**各阈值对应的流动性状态（参考，不纳入门控）：**

| **指标** | **冰点**  | **一般**    | **正常**   | **充裕**     | **极度宽松** |
| ------ | ------- | --------- | -------- | ---------- | -------- |
| 两市成交额  | \<1.5万亿 | 1.5\~2万亿  | 2\~2.5万亿  | 2.5\~3万亿   | ≥3万亿      |
| 涨停家数   | \<20    | 20\~50    | 50\~80   | 80\~100    | >100     |
| 跌停家数   | >30     | 15\~30    | 5\~15    | \<5        | \<3      |
| 涨停/跌停比 | \<1     | 1\~2      | >2       | >3         | >5       |
| 连板高度   | ≤2板     | 2\~3板     | 3\~5板    | 5\~7板      | ≥7板      |

## 三、市场状态分级与响应动作

门控通过（≥2项）后，按市场状态决定评分系数和持仓管理策略。判定优先级：trending_down > trending_up > sideways > weak_up > chaos。

| **状态**             | **判定条件**                         | **评分系数** | **开仓** | **持仓管理**    |
| ------------------ | -------------------------------- | -------- | ------ | ----------- |
| **trending\_down** | MA5\<MA10\<MA20 + 收盘\<MA10       | ×0.5     | ❌ 禁止开仓 | 收紧卖出（加速退出）  |
| **trending\_up**   | MA5>MA10>MA20 + 收盘>MA10 + 门控≥2   | ×1.0     | ✅ 正常买入 | 正常卖出规则      |
| **sideways**       | 收盘偏离MA20 \<1.5%                  | ×0.8     | ❌ 禁止开仓 | 自然退出（不主动砍仓） |
| **weak\_up**       | 收盘>MA20 + 门控≥2 + 非以上三种          | ×0.85    | ✅ 谨慎买入 | 正常卖出规则      |
| **chaos**          | 门控\<2（即0或1项通过）                 | 不开仓      | ❌ 禁止开仓 | 不开新仓        |

> **设计说明**：trending\_down 排在首位判定——均线空头时无论门控通过多少项都不开仓，均线结构本身已给出最强信号。

---

## 四、trending\_down 下的收紧卖出规则

进入 trending\_down 状态后，持仓卖出规则从正常版收紧为加速版：

| **卖出规则** | **正常版**                 | **trending\_down版**       |
| -------- | ----------------------- | ------------------------- |
| 破MA10    | 连续**2天**收盘 \< MA10      | **1天**收盘 \< MA10就走        |
| 放量长阴     | 跌幅≥5% + 量比≥2 + 收盘\<MA10 | 跌幅≥3% + 量比≥1.5 + 收盘\<MA10 |
| 日内回撤     | 日内回撤≥5%减仓               | 日内回撤≥3%减仓                 |
| 板块走弱     | 板块明显走弱减仓                | 板块走弱立刻减仓                  |

以下仅做辅助判断，不影响开仓/锁仓判定：

## 六、执行流程图

```
每日收盘 →
  ├─ 硬拦截检查
  │    ├─ 触发任一 → 锁仓+全清，结束
  │    └─ 未触发 → 继续
  ├─ 门控检查（4项）
  │    ├─ 通过≥2项 → 继续判定状态
  │    ├─ 通过<2项 → chaos状态，不开仓
  ├─ 市场状态判定（按优先级）
  │    ├─ trending_down → ×0.5，不开仓+收紧卖出【最先判定】
  │    ├─ trending_up → ×1.0，正常买入+正常持仓
  │    ├─ sideways → ×0.8，不开仓+自然退出
  │    ├─ weak_up → ×0.85，谨慎买入+正常持仓
  │    └─ chaos → 不开仓+不开新仓
```

## 附：关于主线的说明

门控中**不含板块/主线检查**。主线相关逻辑应放在**选股环节**而非市场门控，原因：

1. **门控回答"能不能交易"**，只需宏观+流动性+情绪数据，不依赖个股/板块维度。
2. **主线回答"能不能找到猎物"**，属于选股层面的过滤条件——个股是否属于今日活跃板块，应与股票池绑定。
3. 如果把主线放在门控，"今天有主线但你的自选股全都不在主线里"和"今天没主线但你的某只股独立逻辑走强"都会产生错误判断。
