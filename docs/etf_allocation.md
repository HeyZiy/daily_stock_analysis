# ETF 长期配置策略

> 主账户压舱石。中性基准写死，每日估值门控驱动战术偏移，偏离触发再平衡。

---

## 一、定位

ETF 配置和趋势交易**完全独立**，使用不同的 gate：

| | ETF 配置（主账户） | 趋势交易（子账户） |
|---|---|---|
| 资金占比 | 重仓 | 轻仓（1 万练手） |
| 操作频率 | 月度审视，偏离触发再平衡 | 日/周 |
| **Gate 类型** | **估值 Gate**（PE 分位，逆向） | **趋势 Gate**（均线+量能，顺势） |
| 哲学 | 低买高卖（别人恐惧我贪婪） | 追涨杀跌（趋势跟随） |
| 操作方式 | 偏离触发再平衡建议，手动执行 | 信号触发买卖建议，手动执行 |

## 三、战术偏移（估值门控驱动）

**核心理念：逆向配置。便宜时多买，贵时少买。**  
与趋势策略的均线 gate 完全不同。

使用三维信号综合判断（`src/etf/allocation_gate.py`）：

### 信号 1：PE 分位（主信号）

数据源：A 股全市场 PE，近 5 年历史分位

| PE 分位 | 基础偏移 | 含义 |
|---|---|---|
| < 20% | **+15%** | 极度低估，大力超配权益 |
| 20-40% | **+10%** | 低估，适度超配 |
| 40-60% | **±0** | 合理估值，中性 |
| 60-80% | **−10%** | 高估，适度减配 |
| > 80% | **−20%** | 极度高估，大幅撤退 |

### 信号 2：股债性价比（修正 ±5%）

比较沪深300 盈利收益率（1/PE）与 10 年期国债收益率。  
利差越大，股票相对债券越便宜。

| 利差 | 修正 | 含义 |
|---|---|---|
| > 5% | **+5%** | 股票极具性价比 |
| 3-5% | **+2%** | 偏便宜 |
| 2-3% | **±0** | 中性 |
| 1-2% | **−2%** | 偏贵 |
| < 1% | **−5%** | 股票性价比极低 |

### 信号 3：恐慌信号（修正 +5%，仅正向）

触发条件：上证指数连跌 3 天以上 + 成交量萎缩至近 20 日均量的 80% 以下。  
触发时额外加仓 5%（逆势捡筹码），但不触发时不减。

### 偏移分配规则

- 最终偏移 = 信号 1 + 信号 2 + 信号 3，限制在 [−40%, +20%]
- 增仓时：按各权益 ETF 占权益总比例等比例分配
- 减仓时：按波动排名从高到低优先减仓
- 黄金不减仓

## 四、当前目标配比

```
当前目标 = 中性基准 + 战术偏移

例 — PE 分位 25%（低估）+ 股债利差 4%（+2%）→ 最终偏移 +12%：
  A500:    17% + 12%×(17/67) ≈ 20.0%
  红利:    14% + 12%×(14/67) ≈ 16.5%
  ...
  现金:    29% − 12% = 17%

例 — PE 分位 75%（高估）+ 股债利差 1.5%（−2%）→ 最终偏移 −12%：
  消费:     8% − 12%×(8/67) ≈ 6.6%
  ...
  现金:    29% + 12% = 41%
```

## 五、再平衡规则

### 触发条件

| 条件 | 阈值 | 动作 |
|---|---|---|
| 单类偏离 | 实际 vs 目标 偏差 > 5% | 生成再平衡建议 |
| 整体偏离 | 所有类别偏差绝对值之和 > 15% | 强制再平衡建议 |

### 再平衡方式

- 不要求精确匹配目标，优先减少操作次数
- 单类偏差 < 2% 忽略（避免碎股交易）
- 调仓指令格式：`BUY/SELL ETF名(代码) X股 ≈ X元 — 原因`
- CASH（现金/逆回购）不生成买卖指令

### 执行节奏

- 每日盘后运行分析模式，出报告 + 推送通知
- 用户自行在券商操作，操作后更新 `data/positions.json`
- 建议月度集中操作，减少日常折腾

## 六、持仓管理

手动维护 `data/positions.json`：

```json
{
  "updated": "2026-07-24",
  "total_assets": 1000000,
  "positions": {
    "563360": {"name": "A500ETF",    "shares": 11000, "cost": 1.334},
    "513100": {"name": "纳指ETF",    "shares": 2000,  "cost": 1.845},
    "159934": {"name": "黄金ETF",    "shares": 500,   "cost": 9.778}
  }
}
```

- `total_assets`：总资产（含现金/逆回购）
- `shares`：持有份额
- `cost`：持仓成本（仅记录，不影响计算）

每次实际交易后手动更新 `shares` 和 `total_assets` 即可。

### 使用方式

```powershell
# 手动模式（默认，无 MX_APIKEY 时自动启用）
python etf_allocation.py --manual

# 不发送通知
python etf_allocation.py --manual --no-notify
```

## 七、卫星仓 — 板块轮动

核心仓位不动，卫星仓独立管理，由 `src/etf/sector_rotation.py` 驱动。

### 定位

| | 核心仓 | 卫星仓 |
|---|---|---|
| 仓位上限 | 90%+ | 10% |
| 管理方式 | 中性基准 + PE 估值偏移 + 再平衡 | 动量排名轮动 |
| 触发频率 | 月度偏离触发 | 每日排名检查 |
| 标的池 | `CORE_BASELINE` | `SATELLITE_POOL` |
| 盈亏隔离 | — | 卫星仓盈亏不影响核心仓再平衡 |

### 评分体系

每个卫星 ETF 每日打分（0-100），四个维度：

| 维度 | 权重 | 计算 |
|---|---|---|
| 20 日涨跌幅 | 30% | >10% 满分，0% 以下衰减 |
| 5 日涨跌幅 | 25% | >5% 满分 |
| 均线排列 | 25% | MA5>MA10>MA20 满分，仅 MA5>MA10 给一半 |
| 量能确认 | 20% | 5 日均量 / 20 日均量，>1.5x 满分 |

### 进出规则

| 规则 | 条件 |
|---|---|
| 激活前提 | PE 分位 < 60%（非高估时激活，高估时全清） |
| 进入信号 | 连续 **2 天** 得分排名前 3，确认进入 |
| 退出信号 1 | 得分跌破 **40** 分，立即退出 |
| 退出信号 2 | 连续 **3 天** 不在前 3，确认退出 |
| 持仓上限 | 最多 **2 只**，总仓位不超过总资产 **10%** |
| 分配方式 | 入选 ETF 等权分配 |

### 状态持久化

排名连续天数和活跃状态保存在 `data/rotation_state.json`：

```json
{
  "top3_streak": {"515010": 2, "588170": 1},
  "not_top3_streak": {},
  "active": {"515010": true}
}
```

每次运行自动更新，确保「连续 N 天」规则正确。

### 报告输出

每日报告底部新增「卫星仓 — 板块轮动」section，包含：
- 各卫星 ETF 当前得分排名及详细分项
- 候选/持有/触发买入/触发卖出状态标注
- 轮动调仓建议（买入/卖出，含股数和金额）

## 八、执行流程

```
每日收盘 →
  1. 读取估值门控：PE 分位 + 股债性价比 + 恐慌信号
     → 输出最终权益偏移量
  2. 中性基准 + 偏移 → 当前目标配比
  3. 读取 positions.json + 拉取收盘价 → 计算实际配比
  4. 比较偏离度 + 判断再平衡触发条件
  5. 板块轮动：对卫星仓池打分排名
     → 检查进出条件 → 生成轮动调仓建议
  6. 生成 Markdown 报告（核心仓 + 卫星仓 + 调仓建议）
  7. 推送通知（飞书/钉钉/Discord 等）
  8. 用户在券商执行 → 更新 positions.json
```

```
文件结构：
  src/etf/
    config.py            — 中性基准 + 卫星仓池 + 再平衡阈值
    allocation_gate.py   — 估值门控（三维信号：PE分位+股债性价比+恐慌）
    rebalancer.py        — 再平衡引擎（计算目标、比较持仓、生成报告）
    sector_rotation.py   — 板块轮动引擎（动量排名 + 进出决策）
  etf_allocation.py      — 主入口
  data/
    positions.json       — 手动持仓记录
    rotation_state.json  — 轮动状态（排名连续天数）
    etf_target.json      — 最近一次目标配比（供执行模式用）
```

## 附录：与趋势交易策略的关系

两个策略完全独立，使用不同的 gate：

| Gate 类型 | ETF 配置 | 趋势交易 |
|---|---|---|
| 数据 | A 股 PE 分位 + 国债收益率 + 上证量价 | 上证 MA + 两市成交额 + 涨跌停数 |
| 逻辑 | **逆向**：便宜多买，贵了少买 | **顺势**：趋势好开仓，趋势差空仓 |
| 源码 | `src/etf/allocation_gate.py` | `src/analysis/market_gate.py` |
| PE < 20%（极度低估） | 权益 +15%，现金 −15% | 不影响（看自己的 gate） |
| PE 40-60%（合理） | 中性，不动 | 不影响 |
| PE > 80%（极度高估） | 权益 −20%，现金 +20% | 不影响 |

两者可能同时出现「ETF 在加仓（PE 低估）+ 趋势交易在空仓（均线走坏）」的情况——这不矛盾，因为时间尺度和逻辑不同。
