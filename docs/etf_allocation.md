# ETF 长期配置策略

> 主账户压舱石。中性基准写死，每日 gate 驱动战术偏移，偏离触发再平衡。

---

## 一、定位

| | ETF 配置（主账户） | 趋势交易（子账户） |
|---|---|---|
| 资金占比 | 重仓（90%） | 轻仓（1 万练手） |
| 操作频率 | 月/季度 | 日/周 |
| 市场判断 | 共享 gate | 共享 gate |
| gate 的作用 | 决定战术偏移量 | 决定能否开仓 + 评分系数 |
| 操作方式 | 偏离触发再平衡建议，手动执行 | 信号触发买卖建议，手动执行 |

---

## 二、中性基准

反映长期信念，不随市场波动。半年或一年审视一次，平时不动。

| 类别 | 资产 | 中性配比 | 理由 |
|---|---|---|---|
| A 股宽基 | 沪深 300 ETF（510300） | 20% | 大盘 Beta，经济基本盘 |
| A 股宽基 | 中证 500 ETF（510500） | 10% | 中盘成长补充 |
| 成长弹性 | 创业板 50 ETF（159915） | 5% | 进攻弹性 |
| 成长弹性 | 科创 50 ETF（588000） | 5% | 硬科技弹性 |
| 红利价值 | 红利 ETF（510880） | 5% | 高股息防御 |
| 海外 | 纳指 ETF（513100） | 5% | 美元资产分散 |
| 港股 | 恒生 ETF（159920） | 5% | 港股核心暴露 |
| 商品 | 黄金 ETF（518880） | 5% | 极端风险对冲 |
| 债券 | 国债 ETF（511010） | 15% | 安全垫 |
| 现金 | 货币 ETF（511880） | 25% | 弹药 + 流动性缓冲 |

> 合计：权益类 55% / 固收+现金 40% / 黄金 5%
> 
> 中性状态下是中等偏进攻的配置。高现金比例不是浪费——给 gate 战术偏移提供挪移空间，极端状态下也有弹药。

## 三、战术偏移（gate 驱动）

每日收盘后，根据 `market.md` 中的市场状态对中性基准做临时偏移。偏移量从现金池进出，不动其他类别自身比例。

| gate 状态 | 权益类偏移 | 现金偏移 | 说明 |
|---|---|---|---|
| **trending_up** | +15% | −15% | 全面进攻，现金降至 10% |
| **weak_up** | +10% | −10% | 温和进攻，现金降至 15% |
| **sideways** | ±0 | ±0 | 维持中性，不动 |
| **trending_down** | −20% | +20% | 大幅收缩，现金升至 45% |
| **chaos** | −30% | +30% | 极限防守，现金升至 55% |
| **hard_intercept** | −40% | +40% | 全面撤退，现金升至 65% |

**偏移分配规则：**
- 增仓时：按各类别占权益总比例等比例分配（A 股宽基 30/55 权重最高）
- 减仓时：优先减波动率最高的类别（创业板 > 科创 > 港股 > 中证 500 > 纳指 > 沪深 300 > 红利 > 国债 > 黄金）
- 黄金和国债在 trending_down / chaos / hard_intercept 时不减仓

---

## 四、当前目标配比

```
当前目标 = 中性基准 + 战术偏移

例 — trending_up：
  沪深 300: 20% + 15%×(20/55) ≈ 25.5%
  中证 500: 10% + 15%×(10/55) ≈ 12.7%
  ...
  现金:     25% − 15% = 10%

例 — trending_down：
  沪深 300: 20% − 20%×(20/55) ≈ 12.7%（优先减创业板/科创）
  ...
  现金:     25% + 20% = 45%
```

## 五、再平衡规则

### 触发条件

| 条件 | 阈值 | 动作 |
|---|---|---|
| 单类偏离 | 实际 vs 目标 偏差 > 5%（绝对值） | 生成再平衡建议 |
| 整体偏离 | 所有类别偏差绝对值之和 > 15% | 强制再平衡建议 |
| 月度检查 | 每月第一个交易日 | 即使未触发也生成检查报告 |

### 执行时机（gate 影响）

| gate 状态 | 偏离触发时 |
|---|---|
| trending_up / weak_up | 暂缓执行（让利润跑，偏差阈值放宽至 8%） |
| sideways | 正常执行 |
| trending_down / chaos / hard_intercept | 立即执行（去风险优先，偏差阈值收紧至 3%） |

### 再平衡方式

- 不要求精确匹配目标，优先减少操作次数
- 单类偏差 < 2% 忽略（避免碎股交易）
- 建议格式：`卖出 XX（金额）→ 买入 YY（金额）`，给出具体股数（按当日收盘价估算）

## 六、持仓管理

### 当前方式：手动维护

`data/positions.json` 记录实际持仓，用户手动更新：

```json
{
  "updated": "2026-07-21",
  "positions": {
    "510300": {"name": "沪深300ETF", "shares": 10000, "cost": 4.20},
    "510500": {"name": "中证500ETF", "shares": 5000, "cost": 6.80}
  },
  "cash": 50000
}
```

脚本读取 gate → 算目标 → 比较 positions → 生成再平衡指令 → 推送通知。

用户执行后在 GitHub 网页上编辑 `positions.json` 写回即可。

## 七、卫星仓（未来扩展）

主仓位不动，卫星仓用于：

- **行业轮动**：当某个行业板块连续走强（主线逻辑），临时超配对应行业 ETF
- **主题/事件**：短期政策或事件驱动的行业 ETF 机会
- **卫星仓位上限**：总资产的 5%-10%
- **卫星仓和主仓隔离**：卫星亏损不影响主仓再平衡

> ⚠️ 卫星仓的进出规则待后续设计。当前只保留主仓逻辑。

## 八、执行流程

```
每日收盘 →
  1. 读取 gate 状态（market_gate 模块）
  2. 计算战术偏移 → 当前目标配比
  3. 读取 positions.json → 比较偏离度
  4. 判断再平衡触发条件 + gate 影响执行时机
  5. 生成建议 → 推送通知
  6. 用户在 broker 执行 → 更新 positions.json
```

## 附录：与趋势交易策略的关系

两个策略共享 `src/market_gate.py` 的 gate 输出，但用法不同：

| | ETF 配置 | 趋势交易 |
|---|---|---|
| trending_up | 权益类 +15%，现金 −15% | ×1.0，正常买入 |
| weak_up | 权益类 +10%，现金 −10% | ×0.85，谨慎买入 |
| sideways | 维持中性，不动 | ×0.8，不开仓，自然退出 |
| trending_down | 权益类 −20%，现金 +20% | ×0.5，不开仓，收紧卖出 |
| chaos | 权益类 −30%，现金 +30% | 不开仓 |
| hard_intercept | 权益类 −40%，现金 +40% | 锁仓 + 全清 |

两者从不矛盾——趋势交易在 trending_up 且 gate≥2 时开个股仓，ETF 同时也在加权益。趋势交易在 trending_down 时空仓，ETF 也减权益。同一套 gate，两个账户各自执行。
